# دكان زمان — الموقع الرسمي (Dokan Zaman)

موقع شركة **دكان زمان للتوريدات العمومية** — شريككم الموثوق في التوريدات والتشغيل.
المشروع يحتوي على تصميمين كاملين للمقارنة بينهما، وكلاهما يدعم المظهر الفاتح والداكن ويعمل على الموبايل.

## فكرة البناء

الصفحة الرئيسية **نظرة عامة خفيفة**: كل قسم فيها يجيب عن سؤال واحد ويحوّل الزائر إلى الصفحة الداخلية التي فيها التفاصيل.

| القسم في الرئيسية | غرضه | التفاصيل في |
|---|---|---|
| الواجهة (Hero) | من نحن في جملة + زر «اطلب عرض سعر» | — |
| ماذا نورّد؟ | نظرة سريعة على المجالات التسعة | صفحة مجالات التوريد |
| كيف نعمل؟ | الخطوات الخمس من الطلب إلى التسليم | صفحة كيف نعمل |
| إدارة المشتريات | ثلاثة أرقام تلخّص الخدمة | صفحة إدارة المشتريات (فيها الحاسبة) |
| لماذا دكان زمان؟ | أربعة أسباب للثقة | صفحة من نحن |
| تواصل معنا | نموذج طلب عرض السعر | — |

## الصفحات

| الصفحة | التصميم 1 | التصميم 2 |
|---|---|---|
| الرئيسية | `index.html` | `design-2.html` |
| مجالات التوريد | `categories.html` | `d2-categories.html` |
| كيف نعمل (نظام التوريد وأساليبه) | `services.html` | `d2-services.html` |
| إدارة المشتريات (النطاق، القيمة، نموذج العمل والحاسبة، مراحل التنفيذ) | `procurement.html` | `d2-procurement.html` |
| من نحن (الرسالة، القيم، لماذا نحن، العملاء) | `about.html` | `d2-about.html` |

- **التصميم 1:** ناعم وفاتح — خلفية كريمي، كروت بظلال ناعمة، شريط تنقل كامل العرض.
- **التصميم 2:** Bold Bento — مربعات بألوان صريحة (أسود + برتقالي)، قائمة عائمة، شريط مجالات بالسحب.

## التشغيل

لا يحتاج المشروع إلى أي تثبيت أو أدوات بناء — افتح `index.html` في المتصفح مباشرة،
أو ارفع المجلد كما هو على أي استضافة ملفات ثابتة (مثل GitHub Pages).

## التقنيات

- **HTML + CSS + JavaScript** بدون مكتبات أو frameworks.
- خط **Readex Pro** (التصميم 1) و **Alexandria** (التصميم 2) من Google Fonts.
- الأيقونات SVG مدمجة داخل الصفحة (رسمها مأخوذ من Lucide).
- المظهر الفاتح/الداكن بمتغيرات CSS ويُحفظ اختيار الزائر في `localStorage`.
- الأداء: الحركات تعتمد على `transform` و `opacity` فقط، والحركات المتكررة تتوقف عندما تكون خارج الشاشة، والصور بصيغة WebP وتُحمَّل عند الاقتراب منها.

## هيكل الملفات

```
*.html              صفحات التصميم 1 (index, categories, services, procurement, about)
design-2.html, d2-*.html   صفحات التصميم 2
css/style.css       تنسيقات التصميم 1 (كل صفحاته)
css/design-2.css    تنسيقات التصميم 2 (كل صفحاته)
js/main.js          تفاعلات التصميم 1 (كل صفحاته)
js/design-2.js      تفاعلات التصميم 2 (كل صفحاته)
assets/             الشعار (فاتح/داكن) والصور
assets/img/CREDITS.md   مصادر الصور
```

## ملاحظات

- روابط ملفات CSS و JS في كل الصفحات تنتهي برقم نسخة (`?v=...`). عند تعديل أي ملف منها غيّر هذا الرقم في كل الصفحات، حتى لا يعرض متصفح الزائر الملف القديم مع الصفحة الجديدة.
- شريط التنقل والفوتر مكرران داخل كل صفحة (لا توجد أداة بناء)، فأي تعديل عليهما يُطبَّق على كل الصفحات.
- لا يوجد رابط بين التصميمين داخل الموقع؛ التصميم 2 يُفتح مباشرة من `design-2.html`.
- بيانات التواصل (رقم الهاتف والبريد والموقع) مأخوذة من العرض التقديمي للشركة، ورقم الهاتف فيها مؤقت ويجب تحديثه.
- نموذج «اطلب عرض سعر» يفتح تطبيق البريد لدى الزائر برسالة جاهزة؛ الإرسال المباشر يحتاج خادمًا أو خدمة نماذج.
- جميع الصور برخصة CC0 (استخدام حر بدون شرط الإسناد) — التفاصيل في `assets/img/CREDITS.md`.

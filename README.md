# دكان زمان — الموقع الرسمي (Dokan Zaman)

موقع شركة **دكان زمان للتوريدات العمومية** — شريككم الموثوق في التوريدات والتشغيل.
تصميم **Bold Bento**: مربعات بألوان الشعار (كحلي + برتقالي)، شريط تنقل ثابت، وزر واتساب عائم، ويعمل على الموبايل.

## فكرة البناء

الصفحة الرئيسية **نظرة عامة خفيفة**: كل قسم فيها يجيب عن سؤال واحد ويحوّل الزائر إلى الصفحة الداخلية التي فيها التفاصيل.

| القسم في الرئيسية | غرضه | التفاصيل في |
|---|---|---|
| الواجهة (Hero) | من نحن في جملة + زر «اطلب عرض سعر» + تتبع طلب نموذجي | صفحة من نحن |
| ماذا نورّد؟ | المجالات التسعة في كروت بالصور | صفحة مجالات التوريد |
| إدارة المشتريات | ثلاثة أرقام تلخّص الخدمة | صفحة من نحن |
| لماذا دكان زمان؟ | أربعة أسباب للثقة | صفحة من نحن |

## الصفحات

| الصفحة | الملف |
|---|---|
| الرئيسية | `index.html` |
| مجالات التوريد | `categories.html` |
| صفحة المجال (المنتجات بالصور والأسعار وماذا نقدم) — صفحة واحدة لكل المجالات | `category.html?c=cleaning` |
| عملاؤنا (شعارات العملاء في شريطين متحركين + القطاعات التي نخدمها) | `clients.html` |
| تواصل معنا (بيانات التواصل ونموذج طلب عرض السعر) | `contact.html` |
| من نحن (من نحن، الرسالة والقيم، كيف نعمل، إدارة المشتريات) | `about.html` |

## التشغيل

لا يحتاج المشروع إلى أي تثبيت أو أدوات بناء — افتح `index.html` في المتصفح مباشرة،
أو ارفع المجلد كما هو على أي استضافة ملفات ثابتة (مثل GitHub Pages).

## التقنيات

- **HTML + Tailwind CSS + JavaScript**. Tailwind يعمل من CDN (`https://cdn.tailwindcss.com/3.4.17`) بدون أي أدوات بناء،
  لذلك تحتاج الصفحات اتصالًا بالإنترنت لتظهر بتنسيقها (مثل خط Google Fonts).
- خط **IBM Plex Sans Arabic** من Google Fonts.
- الأيقونات SVG مدمجة داخل الصفحة (رسمها مأخوذ من Lucide).
- كل التنسيق بكلاسات Tailwind داخل الصفحات والقوالب. الألوان والخط ومقاسات الشاشات والمكوّنات المشتركة
  (الكارت `tile`، الأزرار `pill`، الأقسام `sec`، كارت الصورة `supply-card`، حقول النموذج `f`…) في `js/tailwind.config.js`.
  غيّر لونًا أو مكوّنًا هناك مرة واحدة فيتغيّر في كل الصفحات.
- مقاسات الشاشات (من الأكبر للأصغر): `tab` ≤1240 · `lg` ≤1080 · `md` ≤960 · `sm` ≤760 · `xs` ≤600 — مثال: `grid-cols-3 lg:grid-cols-2 xs:grid-cols-1`.
- الأداء: الحركات تعتمد على `transform` و `opacity` فقط، والحركات المتكررة تتوقف عندما تكون خارج الشاشة، والصور بصيغة WebP وتُحمَّل عند الاقتراب منها.

## هيكل الملفات

```
index.html, categories.html, category.html, about.html, clients.html, contact.html   الصفحات
js/tailwind.config.js        إعدادات Tailwind: الألوان، الخط، مقاسات الشاشات، والمكوّنات المشتركة
css/style.css                أساس صغير تحت Tailwind: المسافات العامة، إعادة الضبط، الحركات (keyframes)، وظهور الأقسام عند التمرير
js/layout.js                 الأجزاء المشتركة: الشريط العلوي، قائمة الموبايل، الفوتر، زر واتساب، زر الرجوع لأعلى،
                             الأيقونات، وبيانات التواصل (كائن SITE في أول الملف) — عدّلها هنا مرة واحدة
js/main.js                   التفاعلات (القائمة، الحركات، العدادات، النموذج…)
js/catalog.js                بيانات المجالات والمنتجات (الاسم، الوصف، السعر، الصور)
js/category.js               يبني صفحة المجال من catalog.js
js/clients.js                شعارات العملاء + الشريط المتحرك في صفحة «عملاؤنا»
assets/files/company-profile.pdf   ملف «ملف تعريف الشركة» (يُحمَّل من الشريط العلوي)
assets/logos/                الشعار بألوانه الأصلية (برتقالي وكحلي) + العلامة
assets/img/categories/       صورة لكل مجال توريد
assets/img/site/             صور عامة للموقع
assets/img/clients/          شعارات العملاء
assets/img/products/<المجال>/<المنتج>/   صور كل منتج: 1.webp, 2.webp …
```

**الأجزاء المشتركة:** كل صفحة فيها أماكن فاضية مثل `<div data-site="header"></div>` و `<div data-site="footer"></div>`، ويرسم `js/layout.js` مكانها الشريط العلوي والفوتر. أي تعديل في `js/layout.js` يظهر في كل الصفحات.

## تعديل المنتجات والأسعار

كل بيانات المنتجات في ملف واحد: `js/catalog.js`. لكل منتج سطر فيه الاسم والوصف والسعر والصورة:

```js
{ name: 'المنظفات', desc: '…', price: 100, unit: '', images: ['assets/img/products/cleaning-detergents.webp', 'assets/img/products/cleaning-detergents-2.webp'] },
```

- **السعر:** غيّر الرقم في `price` (يظهر بالأرقام العربية تلقائيًا). اكتب `null` ليظهر «السعر عند الطلب». الأسعار الحالية (١٠٠ ج.م) مؤقتة.
- **الصور:** `images` قائمة صور المنتج؛ الأولى هي الرئيسية والباقي يظهر بالتقليب (أسهم / نقاط / سحب). صور كل منتج في مجلده `assets/img/products/<المجال>/<المنتج>/`؛ لتغيير صورة استبدل الملف بنفس الاسم، ولإضافة صورة ضعها في المجلد وأضف مسارها داخل `images`. يفضّل أن تكون بنسبة ٣:٢ (مثل 720×480). لو الصورة غير موجودة تظهر صورة المجال مكانها.
- **الوحدة (اختياري):** مثل `unit: 'للكرتونة'` تظهر بجانب السعر.
- **إضافة منتج:** انسخ سطر منتج والصقه تحته وعدّل بياناته.
- **ماذا نقدم في المجال:** في `services` لكل مجال.
- بعد أي تعديل في `catalog.js` غيّر رقم النسخة `?v=` في سطر `catalog.js` داخل `category.html`. 

## السرعة

- الصور WebP مضغوطة (٧٢٠×٤٨٠ للمنتجات) وتُحمَّل عند الاقتراب منها؛ صور التقليب داخل الكارت تُحمَّل عند الوصول لها.
- الخط يُحمَّل بدون أن يوقف عرض الصفحة، والسكربتات كلها `defer`.
- روابط CSS/JS المحلية تنتهي برقم نسخة `?v=` حتى يحصل الزائر على آخر نسخة.

## ملاحظات

- روابط ملفات CSS و JS في كل الصفحات تنتهي برقم نسخة (`?v=...`). عند تعديل أي ملف منها غيّر هذا الرقم في كل الصفحات، حتى لا يعرض متصفح الزائر الملف القديم مع الصفحة الجديدة.
- زر واتساب العائم يفتح محادثة على الرقم المكتوب في `SITE.whatsapp` داخل `js/layout.js` برسالة جاهزة.
- نموذج «اطلب عرض سعر» يفتح تطبيق البريد لدى الزائر برسالة جاهزة؛ الإرسال المباشر يحتاج خادمًا أو خدمة نماذج.
- لينك **«اعرف شركتنا !»** في الشريط العلوي يحمّل الملف `assets/files/company-profile.pdf`. لتغييره: ضع الملف الجديد مكانه بنفس الاسم، أو غيّر المسار في `SITE.companyFile` داخل `js/layout.js`.
- أيقونات **فيسبوك / إنستجرام / لينكدإن** في الفوتر تأخذ روابطها من `SITE.social` داخل `js/layout.js`؛ ضع رابط صفحة الشركة مكان الرابط العام.
- **شعارات العملاء:** ضع الشعارات في `assets/img/clients/` (PNG أو SVG بخلفية شفافة)، واكتب اسم كل عميل ومسار شعاره في أول `js/clients.js`.
